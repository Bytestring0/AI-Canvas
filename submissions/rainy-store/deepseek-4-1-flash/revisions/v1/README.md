# 雨夜便利店街角 · 三渲二微缩三维模型

一个可以自由拖拽、旋转、缩放的**微缩三维模型**（diorama）：日本住宅区十字路口的便利店，雨夜，三渲二（cel-shading）画风。整个场景——几何、贴图、光效、动画——都由一个 `index.html` 里的原生 WebGL2 代码实时生成，**没有任何外部依赖**：没有 CDN、没有网络请求、没有 npm、没有构建步骤、没有后端、没有图片或字体文件。

打开方式：双击 `index.html`（或拖进浏览器窗口）。页面没有任何 UI 控件，只有一整个可以抓取旋转的模型。

## 二、实现清单（对照需求）

### 底座与构图
- 40×40 世界单位（1 单位 = 0.5 m，即 20 m × 20 m）的正方形底座，下方是三层收台（台阶式）模型座，含一圈黄铜色装饰线，强化“收藏级微缩模型”的实体感。
- 底座悬在纯夜色背景之上，四周被雾与暗角收拢，形成“模型摆在暗房里”的观感。
- 构图紧凑：便利店占对角线一侧，路口、斑马线、小巷、对街住宅在另一侧层层退后，形成前中后景。

### 便利店外观
- **招牌**：横向门头灯箱（`ココマート 便利 OPEN 24 HOURS`）、侧向副招牌、竖向圆柱塔招（コ / マ / ー / ト 四段 + `24H` 底牌），灯管有随机闪断。
- **玻璃橱窗**：整面落地玻璃，竖向铝框分格，含朝阳街角的转角窗；玻璃上有雨水流痕、水珠与环境反射。
- **自动门**：双开平移门，进入“感应范围”后自动向两侧滑开，停留后关闭（顶点级动画，非贴图假象）。
- **雨棚**：绿色檐口 + 白色肋条 + 棚下嵌入式暖光灯，棚口持续滴水。
- **门口地垫**：入口内外两块——`傘 お忘れなく` 提醒垫与品牌方形垫，以及地面的绿色导视贴。
- **其他外立面**：空调外机（含风扇盘管细节）、落水管、电表箱、告示板、后巷卷闸通风口、屋顶机柜与风机盘管、太阳能板。

### 街区设施
- **自动售货机 ×2**（蓝白冷饮 + 红色热饮），面板贴图过程式绘制，机身侧边有冷光条。
- **自行车 ×2**（一辆停门口、一辆斜靠侧墙），轮圈辐条为真实几何。
- **雨伞架**：金属架内插六把不同颜色的伞。
- **垃圾桶**：两只圆柱分类桶 + 底座托盘。
- **路灯 ×3**（两侧人行道 + 远端一根冷白路灯）。
- **电线杆 ×3 + 电线**：三档横担、绝缘子、柱上变压器、杆牌，电线使用悬链线（catenary）下垂的多段圆柱，共 13 条，包含引入便利店的入户线。
- **路牌**：街名牌（`ココロ町 二丁目`）、凸面反光镜、`A` 字立牌、小黑板、消防栓、停车位划线、护栏、排水沟格栅、井盖、减速带、盲道砖。
- **小巷入口**：竖栏栅门、巷内暖色灯笼、塑料周转箱、外挂空调、竖向管线、巷尾红色信号灯。
- **斑马线 ×2 + 停表线 + 中心虚线 + 边线**，湿面有强反射。
- **红绿灯 ×2**：三灯箱体内亮一盏，行人灯另有小绿人；**会按周期在红/绿之间变化**，并且变化会带动湿地面上的色斑跟着变。

### 店内（透过大玻璃完整可见，无人物）
- 饮料冷柜：六层货架 + 冷蓝发光玻璃门 + 铝框分格。
- 杂志架：四层斜插陈列，封面为程序生成的彩色图块。
- 三排中岛货架（gondola）：双侧陈列 + 黄色价格条 + 端头促销堆头。
- 关东煮台：汤槽、汤色、串物，上方热风玻璃罩。
- 便当热柜：三层陈列 + 内嵌暖光。
- 饭团/三明治开放式冷柜：白色冷光条。
- 炸物保温柜。
- 收银台：台面、点钞区、收银机（发光屏）、扫码枪、购物袋架、菜单灯条。
- 咖啡机：自绘面板（COFFEE / 出杯口 / 三色按键 / 咖啡液）。
- ATM 岛 + 品牌海报。
- 后墙海报 ×4、储物柜、通往后仓的门 + 门把手、品牌灯箱墙。
- 天花板灯盘阵列、收银台上方三盏吊灯。

### 灯光与氛围
- 4 个动态点光（门头柱灯 / 左右路灯 / 售货机冷光）在片元着色器内做分档（toon）衰减。
- 店内填充光让室内整体偏暖，与室外冷雨形成明确冷暖分层。
- 招牌灯箱、灯盘、冷柜、售货机、窗户、红绿灯均为自发光材质，参与后期 bloom。
- 雾（按距离指数衰减）把远处街区并入夜色。

### 动画（全部常驻运行）
| 动画 | 实现方式 |
| --- | --- |
| 持续降雨 | 3400 条雨丝，instanced 绘制，每滴 4 顶点面向相机的条状面片，落地后重生在便利店范围之外 |
| 雨棚滴水 | 棚口 26 条竖向水线，各自相位下坠 |
| 水洼涟漪 | 路面着色器内 4 组环形波 + 每片水洼独立的椭圆掩码 |
| 招牌闪烁 | 灯管闪断（多频正弦叠加 + 偶发长暗），同时影响柱灯点光强度 |
| 玻璃上雨水 | 24 条按列随机相位的水流 + 玻璃水滴点阵 |
| 自动门开合 | 顶点缓冲区内平移门扇，感应 → 开 → 停 → 关，随机间隔 |
| 湿地反光 | 路面自写的“街道倒影”函数：天空/建筑窗光/红绿灯光斑/霓虹拖尾 + 水洼高光 + 波荡扰动 |
| 红绿灯变化 | `sig` 状态按周期切换，红/绿光斑在水面与对面墙体上同步 |
| 镜头 | 全程无 UI，无自动巡航，必须由用户操作（尊重使用者的掌控感） |

### 交互（无任何可见控件）
- **拖拽**：旋转（偏航 + 俯仰，俯仰限制在 0.10–1.40 rad，不会翻到底盘下面）。
- **Shift + 拖拽 / 右键拖拽**：平移观察目标（限制在街区范围内）。
- **滚轮 / 双指捏合**：缩放（距离 11–150）。
- **双击**：回到初始视角。
- **键盘**（焦点在画布上时）：

| 按键 | 功能 |
| --- | --- |
| `←` `→` | 左右旋转 |
| `↑` `↓` | 抬高 / 压低视角 |
| `Shift` + `↑` `↓` | 抬高 / 降低观察目标 |
| `PageUp` / `PageDown` | 推近 / 拉远 |
| `+` / `-` | 推近 / 拉远 |
| `R` | 回到初始视角 |
| `M` | 暂停 / 继续动画 |
| `P` | 保存当前画面为 PNG |

- **无障碍**：画布 `role="application"` + 中文 `aria-label`，另有一份说明性 `.sr` 文本给读屏；焦点环可见。
- **`prefers-reduced-motion: reduce`**：默认关闭自动门与部分动态，雨与时间整体降到 0.35 倍速；系统设置变更会实时生效。按 `M` 可以自行续播。

### 性能与稳健性
- 全场景合并为**一次** `drawElements`（单一交错顶点缓冲 + 单一索引缓冲），顶点 16 float/属性打包。
- 渲染到离屏 FBO（RGBA8 + DEPTH24 深度贴图），再经全屏三角形做后期：深度拉普拉斯描边、8 抽样 bloom、暗角、ACES 压缩。
- 像素比上限 2×，并将离屏分辨率封顶在 1700 px，避免高分屏 / 折叠屏拖垮帧率。
- WebGL2 不可用时给出中文降级提示（不抛栈到界面）。

### 彩蛋
- 竖向塔招的灯管会不定时闪断——连续看十几秒能看到一次明显长暗。
- 自动门有“感应”延迟：关着的门不会因为相机靠近就开，只有周期到了才开，像是真的有人刚走进去。
- 红绿灯换色时，湿路面上的红/绿光斑、以及对面公寓墙上的反光会同步变化。
- 路灯下、售货机前各自有一圈暖/冷光晕落在地面上，与水洼涟漪叠加时会闪。

## 三、技术实现

### 坐标系与尺度
- 1 世界单位 = 0.5 m；底座 40×40。
- `+X` 东（右）、`+Z` 南（朝向观察者）、`+Y` 上。
- 东西向道路 `z ∈ [-20, -9]`；南北向道路 `x ∈ [-20, -9]`。
- 便利店占地 `x ∈ [-6, 8]`、`z ∈ [-8.6, 3.6]`，立面在 `z = 3.6`，层高 6.6（= 3.3 m）。

### 渲染管线
1. **贴图图集**：`1024 × 1024` 的 `Canvas2D` 在启动时过程式绘制全部招牌、海报、售货机面板、咖啡机面板、铺装、沥青、街名牌等，作为一个 `RGBA` 纹理上传（含 mipmap 与各向异性过滤）。**没有任何外部图片**。
2. **几何**：`box / quad / tri / cyl / beam / cable / panel` 等原语把 16-float 顶点写进 JS 数组，随后一次性上传到 GPU。材质由顶点属性 `aMat` 区分：`0` 标准、`1` 湿沥青、`2` 人行道铺装、`3` 玻璃（半透明叠加层）、`4` 植被、`5` 天空、`6` 图集自发光、`7` 纯自发光、`8` 咖啡机面板、`9` 杂志封面。
3. **主通道**：不透明几何 → 关闭混合、开深度写入。
4. **叠加层**：地面光池 / 玻璃雨流 / 雨棚滴水，独立 VAO，`SRC_ALPHA, ONE` 加法混合、关深度写入。
5. **雨**：`drawArraysInstanced(TRIANGLE_STRIP, 0, 4, 3400)`，条状面片按屏幕空间速度方向展开，避免任何纹理。
6. **后期**：全屏三角形 + 深度拉普拉斯描边（阈值按线性化深度差归一化）+ 环形 bloom + 暗角 + ACES。
7. **点光**：4 个点光在片元内做 `(1 - d/r)²` 衰减与两级 `smoothstep` 分档，得到硬边明暗交界（三渲二的骨架）。

### 过程式细节
- **湿路面倒影**：把世界 `xz` 压成一条“竖向街道图”，`hash` 出楼体窗光、红绿灯光斑、霓虹拖尾，再按 `fresnel` 与水洼掩码混合；`wob` 由三组不同频率的正弦叠加，模拟雨点打乱倒影。
- **雨滴落地**：雨丝到达地面高度后立即重生在便利店包围盒之外，保证店内不“下雨”。
- **自动门**：门扇顶点区间在构建时记录（`DOOR.range`），动画时只对这段顶点做 `bufferSubData`，其余顶点不动。

## 四、已知限制

1. **必须支持 WebGL2**。老浏览器（IE、旧 Safari < 15）只显示中文降级提示，不会渲染。
2. **字体依赖系统**。招牌上的日文/中文使用系统字体栈（`Microsoft YaHei`、`PingFang SC`、`Hiragino Sans GB`、`Noto Sans CJK SC` 等）。若系统完全没有 CJK 字体，字会变成方块。这是“零外部依赖”的代价——嵌入 CJK 字体需要数 MB。
3. **没有真实反射探针**。湿地面、玻璃、镜面的“倒影”是风格化函数，而不是场景的真实镜面渲染；换角度时倒影细节不会严格对应真实几何，只在观感上成立。
4. **雨是屏幕空间面片**。极近距离拉近到路面时，能看到雨丝是面向相机的薄片；没有做体积雨。
5. **无阴影贴图**。明暗来自点光 + 分档 + 环境项，物体之间不投射实时阴影（靠描边与明暗层次区分体积）。
6. **无人物**。按需求不放置店员与顾客，店内是“刚离开”的空场状态。
7. **`P` 键保存图片**可能被宿主沙箱拦截（`sandbox="allow-scripts"` 下浏览器可能阻止下载）。拦截时只在控制台留一条警告，不影响场景运行。
8. **移动端性能**视 GPU 而定。低端机型上 3400 条雨丝 + 后期 bloom 可能掉帧；已用像素比上限与分辨率封顶缓解，但没有自适应降级档位。
9. **单帧快照能力**依赖 `toDataURL`，因此只在按下 `P` 的瞬间渲染并立即取图；没有做离线渲染/导出序列帧。
10. 场景是**单街区固定构图**，不提供“切换天气 / 时段 / 街区布局”的开关（避免引入 UI）。
