# 雨夜便利店街角 - AI 微缩场景

## 模型版本
- 具体：可自由拖拽、旋转、缩放观看的微缩三维 AI 场景
- 底层：正方形底座 (100×100)
- 风格：三渲二、浓厚的日式二次元动画

## 创作提示词
从“拖拽、旋转、缩放”出发，搭建一个可以自由拖拽和旋转的微缩三维模型。底层为正方形底座（100×100），内部包含：
- 日式便利店：招牌、玻璃橱窗、自动门、屋檐雨棚、便当区、冰柜、灯箱、收银台
- 典型街角元素：自行车、小巷入口、空调外机、垃圾桶、电线杆、路灯等
整体呈现小巧、精致、可收藏的 AI 场景，氛围安静、治愈，带一点都市夜晚孤独感但依然温暖。美术风格：高精细建模、三渲二卡通渲染、清晰的轮廓、干净材质、湿润夜景霓虹、暖色室内灯光与冷色街景对比。

## 实现限制
- 不调用 AI 接口；使用原生 HTML/CSS/JS，兼容 Chrome/Firefox/Safari
- 响应式：390px 屏幕及以上
- 键盘操作：上/下、左右拖拽底座；↑/↓（可选）缩小底座；Ctrl/Shift 向上缩放
- 鼠标拖拽：影响底座缩放和旋转
- 交互：持续降雨、屋檐滴水、水面积水、自动门开合、雨水沿玻璃滑落、街道路面积水反射灯光、远处交通信号灯微弱变化等
- 基础动效：微小的机械动作（如开门），配合背景动画效果
