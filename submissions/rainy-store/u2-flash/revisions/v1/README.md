## 使用

直接用现代 Chromium、Firefox 或 Safari 打开 `index.html`；也可将整份 HTML 直接放进 `sandbox="allow-scripts"` 的 iframe 中，以 `srcdoc` 或独立沙箱文档运行。无需安装依赖、联网、启动服务器或构建。

- 鼠标左键拖动／单指拖动：旋转视角。
- 鼠标右键拖动、Shift + 拖动／双指移动：平移。
- 滚轮／双指缩放：放大与缩小。
- 方向键：转动及改变俯仰；`+`、`-`：缩放；`W`、`A`、`S`、`D`：平移；`Home`：视角复位。
- 开启系统 `prefers-reduced-motion` 时，降雨、灯光变化、门扇和水纹动画静止，用户操作仍可用。

## 实现

所有资源都包含在单个 HTML 文件中：原生 JavaScript 在 `<canvas>` 上使用自写的正交三维投影、遮挡深度排序、面片绘制、轮廓线和面向透视的文字贴花。建模元素包含完整的正方形底座、L 形转角道路、斑马线、路沿、积水、排水沟、便利店外立面和玻璃、开放展示式屋顶、招牌、入口、贩卖机、带辐条的自行车、雨伞架、垃圾桶、公告板、空调、停车标志、路灯、电线杆、电线、交通信号灯、小巷、植物与护栏。

室内布置包括瓷砖地板、连续货架与彩色商品、后墙饮料冷柜、饭团和便当区、杂志架、收银台、收银屏幕、咖啡机、关东煮展示、促销条幅等。室内特意采用局部剖切顶棚与半透明大面积玻璃，方便从不同角度查看商品陈设。环境使用蓝紫夜色、暖黄店光和珊瑚色设备光、湿路材质、反射色带、店招散射光、雨丝、窗面水迹、檐口滴水、地面波纹、周期滑门、缓慢灯光变化及交通信号光晕营造动画场景感。

本实现不生成任何 UI 控件、不加载任何外部字体、图片、音频、npm 包或 CDN 资源，不发起网络请求，不调用 AI 接口或父页面，也不使用弹窗、本地文件读取、表单或顶层导航。支持响应式 DPR、390px 手机宽度及桌面显示。

## 已知限制

1. 因严格离线且不依赖 WebGL / 第三方引擎，渲染器采用 Canvas 2D 的正交三维多边形排序，而非带硬件深度缓冲的真实光线追踪；个别面片交叠角度下可能存在微小遮挡误差。
2. 霓虹光晕、湿地反光、玻璃雨痕和波纹是艺术化程序模拟，不是物理准确的折射与反射。
3. 商品包装、店招为程序绘制的几何与系统字体，无法保证每个平台的日文字符字形完全一致。
4. 为保障弱性能移动设备运行，场景使用固定复杂度的几何，极高分辨率与极大缩放下细节仍有限。
5. 模型是可操纵的三维投影场景，但不是通用的 GLTF / OBJ 模型编辑器，不能导出单独的网格资产。
