# 雨夜便利店街角 · 微缩三维模型

单文件交付版本 **v1.0.0**（生成日期：2026-10-18）

一个完全自包含的 `index.html`：使用原生 HTML/CSS/JavaScript + Canvas 2D 软件渲染器实现的
**三渲二（Cel Shading）雨夜日式便利店街角微缩景观**。没有 UI 界面元素，场景是一个可自由
拖拽旋转、缩放、平移观察的“收藏级”小模型。

## 运行方式

直接用浏览器打开 `index.html` 即可（双击文件，或任意静态服务器托管）。无需网络、npm、
构建过程或后端。

- 鼠标左键拖拽：旋转视角
- 鼠标右键 / Shift+拖拽：平移视角
- 滚轮 / 触控板捏合：缩放
- 触屏：单指旋转，双指捏合缩放 / 平移
- 键盘：方向键旋转，`Shift+方向键` 平移，`+ / -` 缩放，`R` 复位视角
- 遵循 `prefers-reduced-motion: reduce`：自动关闭降雨、门禁开关、招牌闪烁、信号灯变化等非必要动画

## 场景内容

正方形底座上搭建的完整街角：

- **便利店主体**：白墙、玻璃橱窗（4 联大窗 + 窗棂）、自动滑动门（偶尔开合并在地面投射暖光）、
  红白条纹雨棚、发光招牌（`SUNNY MART / サニーマート / 24H`，带轻微闪烁）、门垫、外侧空调外机。
- **店内陈设（透过大玻璃清晰可见）**：三排货架（货品由程序化贴面绘制）、靠墙饮料柜、冰柜、
  收银台 + 收银机 + たばこ灯箱、咖啡机、关东煮柜台（带上升蒸汽动画）、杂志架、便当/饭团冷藏柜、
  墙面海报、SALE 吊旗、天花板灯管、地面黄色导视、后场金属门。
- **街角元素**：两条湿漉漉的柏油路（车道虚线、斑马线、停车位标线、井盖、排水沟）、人行道与路缘石、
  街角护栏、电线杆与下垂电线、两盏路灯（光锥 + 地面光池）、红绿灯（红黄绿循环）、路牌、停止牌、
  两台自动贩卖机（发光面板与按钮）、自行车、伞架、打开的雨伞、垃圾桶、公告栏、小巷入口、
  西侧邻楼（带灯光窗户与居酒屋招牌）、东侧街对面建筑、店后服务院与栅栏。
- **雨夜氛围**：持续降雨（230 粒子）、屋檐/雨伞边缘滴水、地面积水涟漪、玻璃上的雨水滑痕、
  路灯/招牌/贩卖机在湿路面的反光、远处霓虹散景与月亮、暗角。店内暖光与室外冷色雨夜形成对比。

## 技术实现

- 自研微型 3D 引擎：世界空间建模 → 相机空间变换 → 背面剔除 → 画家算法深度排序 → Canvas 2D 绘制。
- 三渲二风格：扁平双色 Cel 明暗 + 深色轮廓线；自发光面（招牌、玻璃、灯箱）不受光照影响。
- 贴面纹理（货架商品、海报、招牌文字等）通过仿射变换映射到 3D 四边形上，按面纵横比校正，避免拉伸。
- 动态元素：自动门（动态面片）、信号灯、招牌闪烁、雨粒子、水滴、涟漪、反光与光晕（additive 合成）。
- 全部资源内联：无 CDN、无外部图片/字体/声音，无任何网络请求。

## 已知限制

- 采用画家算法排序，极端视角下少数大平面之间可能出现轻微排序瑕疵。
- 招牌文字等为程序化绘制的小尺寸文本，缩放过远时会变得细小。
- 反光/涟漪为屏幕空间近似，不参与逐像素深度遮挡。
- 未使用 WebGL，面片数量控制在约 1000 面/帧以内，以保证中低端设备流畅。
- 因开发环境沙箱禁止启动浏览器，交付前通过 Node 无头渲染桩验证了脚本 12 帧运行无异常；
  建议在真实浏览器中打开确认最终观感。
