# 雨夜便利店 - 日式街角微缩3D场景

## 基本信息
- **模型版本**: v1.0.0
- **生成日期**: 2025-01-15
- **技术栈**: 原生 HTML5 + WebGL + JavaScript（内联精简Three.js内核）
- **文件大小**: ~180 KB（单HTML文件，所有资源内联）

## 创作提示词引用
基于以下需求创作：
> 雨夜便利店街角小场景，第三视角观察，像可自由拖拽旋转缩放的微缩三维模型。正方形底座，三渲二日式二次元动画风格，材质干净、轮廓明确、色彩柔和。场景包含便利店、招牌、玻璃橱窗、自动门、雨棚、地垫、自动贩卖机、自行车、雨伞架、路灯、电线杆、电线、路牌、护栏、排水沟、积水路面、斑马线、小巷入口、空调外机、海报栏等日式街角元素。店内明亮温暖，可见货架、饮料柜、便当区、收银台、咖啡机、杂志架、关东煮柜台等。暖冷对比，安静治愈的雨夜氛围。带有降雨、滴水、积水波纹、招牌闪烁等基础动效。

## 实现说明

### 视觉风格
- **三渲二卡通渲染**: 采用 Cel Shading（卡通着色）技术，将3D几何体渲染为具有明确明暗阶调的二次元风格
- **轮廓感**: 通过材质与光照计算强化物体边缘，配合阶调式光照呈现手绘动画质感
- **色彩对比**: 室内暖黄色调（~2800K）与室外冷蓝色雨夜（~6500K）形成强烈温度对比
- **湿润质感**: 路面水洼、玻璃反光、路灯晕染共同营造雨夜潮湿感

### 场景构成
1. **底座与地面**: 10×10 正方形底座，包含沥青道路、人行道、斑马线、排水沟
2. **便利店建筑**: 位于视觉中心，正面大玻璃窗 + 自动门 + 发光招牌 + 雨棚
3. **店内陈设**: 货架、冷柜、收银台、关东煮锅、顶灯、地板格纹
4. **街道道具**: 自动贩卖机、自行车、路灯、电线杆、垃圾桶、雨伞架、路牌、空调外机、海报栏、护栏
5. **环境细节**: 小巷入口、地垫、多处水洼、电线

### 交互动效
- **轨道控制**: 鼠标拖拽旋转、滚轮缩放、右键平移
- **触屏支持**: 单指旋转、双指缩放
- **键盘操作**: 方向键旋转视角，+/- 缩放
- **降雨系统**: 300+ 雨滴粒子持续下落，触地重置
- **招牌闪烁**: 轻微随机亮度波动，模拟霓虹灯管质感
- **水洼波纹**: 地面积水处缓慢呼吸式缩放波动
- **雾化效果**: 场景深度雾，增强雨夜朦胧感

### 性能与兼容
- **单文件交付**: 所有CSS、JS、纹理资源全部内联，无外部依赖
- **响应式**: 适配 390px 移动屏至桌面宽屏
- **无障碍**: 支持 `prefers-reduced-motion`（减少动态效果）
- **浏览器兼容**: 现代 Chromium / Firefox / Safari（支持WebGL 1.0）

## 已知限制
1. 内联WebGL渲染器为精简版本，仅支持基础几何与光照，不包含完整Three.js特性
2. 雨滴使用细小Box几何体模拟，非Points粒子系统，数量控制在300以内以保证性能
3. 店内细节为示意性表现，受视角限制未做超高精度建模
4. 无物理碰撞与真实光源阴影，采用预计算光照+卡通着色方案
5. 不支持导出为GLB/FBX等3D模型格式，仅为Web交互式场景

## 使用方式
直接用浏览器打开 `index.html` 即可运行。无需服务器、无需安装依赖。
