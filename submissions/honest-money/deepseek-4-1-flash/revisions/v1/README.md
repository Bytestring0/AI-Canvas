# A 股模拟策略：波动率目标趋势跟随（trend-vol-v1）

- 策略标识（memory 内）：`strategy_tag = trend_vol_sampled_v1`，`strategy_version = 1`，`schema = 1`
- 生成模型：由操作者填写
- 生成日期：由操作者填写
- 实测状态：**未实测真实行情**。仅用合成行情做了离线自测（15 项协议/边界用例 + 12 交易日 trace，0 违规）；合成数据不代表真实收益。

程序为单文件、仅标准库，启动即读一次 stdin、输出一次 stdout 后退出：

```
python -X utf8 -I -S /submission/strategy.py
```

---

## 1. 策略逻辑（一句话概括）

**在 8 只受控股票池内，用“跨日动量 + 日内动量”的综合分挑选强势标的，按波动率目标分配仓位，
用组合回撤阶梯、单票止损/移动止损、信号反转与急速下跌规则控制风险；没有合法信号时保持现金。**

### 1.1 数据来源与处理

1. `history` 是每约 10 分钟一次的**当日累计快照**。每只股票在 history 中只保留**最后一个含有效报价**
   的快照作为“最新价”（不做插值、不用中位价代替最新价），用该轮的 `open`、`high`、`low`、
   `reference_close`、`vol` 描述当日状态。
2. 每只股票的报价需满足：`quote_time` 相对本轮 `as_of` 的年龄在 0–600 秒（`max_quote_age_seconds`）
   且当日累计 `vol > 0`，否则该股本轮**不可交易**（缺失不等于价格为零）。
3. `history` 最多 240 点且当天占绝大多数，无法直接算多日动量，因此策略用 memory 自建**日序列**：
   每个交易日为每只股票记录一条 `[日期, 最新价, reference_close]`，最多保留 80 个交易日。
   日收益定义为 `close_t / reference_close_t - 1`（reference_close 是公开未复权日线的前收盘，
   比相邻快照相除更接近日线口径）；缺失时退化为相邻观测日收盘比。
   若某股当日累计成交量为 0，则视为无效快照，不写入序列（避免停牌/无成交被记成 0% 收益）。
4. 时间一律取自输入：`as_of`、`slot`、`quote_time`；**不使用本机时钟**，不自建定时器，不补跑缺失时段。

### 1.2 信号

对每只可交易股票计算：

| 量 | 定义 | 用途 |
|---|---|---|
| 中动量 `mid` | 有 ≥6 日历史：`0.6*r5 + 0.4*r20`；不足时退化为 `r5`、`0.5*r20`、`0.5*r1` | 主信号 |
| 日内动量 `intraday` | `last / open - 1`（当日） | 辅信号 |
| 槽内漂移 `slot_drift` | 当日首个有效快照到最新快照的变化（开盘后不久 `open` 几乎无信息时使用） | 冷启动辅信号 |
| 波动率 `vol` | 最近 ≤20 个日收益的样本标准差；日收益不足 5 个时用 `(当日 high-low)/reference_close*0.6` 兜底，再兜底 2.5% | 仓位分配 |
| 趋势确认 `trend_ok` | 近 3 日均价 ≥ 近 10 日均价 × 0.995（数据不足则不否决） | 过滤 |

**综合分**（数据充足时）：

```
score = 0.65 * mid + 0.45 * intraday
```

历史很短（跨日观测 < 3 天，例如开盘后不久）时自动降级为：
`score = 0.60 * intraday`（要求 |intraday| ≥ 0.3%），再不行用 `score = 0.45 * slot_drift`；
两者都不成立则**不给信号**——不用 10 分钟噪声建仓。

进入候选还需同时满足：有效报价、有成交量、未贴近涨停/跌停（距涨/跌停 0.4% 以内视为贴近）、
当日涨幅 ≤ 8%、`score > MIN_BUY_SCORE`、趋势未破坏、若该股刚从止损离场则处于冷却期之外。

### 1.3 仓位（波动率目标 + 分数倾斜 + 回撤降险）

```
单票目标权重 = clamp(TARGET_VOL / vol, …) * clamp(1 + 4*score, 0.60, 1.30)
               * 组合敞口上限系数 / (当前持仓数 + 1)
目标权重再受 WEIGHT_CAP = 35% 上限约束
```

- 总敞口上限默认 `DEFAULT_GROSS = 1.00`（**基本不使用借款**），遇到组合回撤按阶梯下调：
  回撤 ≥ 8% → 0.80，≥ 15% → 0.50，≥ 22% → 0.25，≥ 28% → 0（停止新开仓）。
- 单笔交易规模下限 `MIN_TRADE_DRIFT = 4%` 净资产：更小的调整不做，避免被 5 元最低佣金和
  双边滑点吃掉收益。
- 持仓的目标权重在**开仓时写入 memory**（`pos[symbol].tw`），此后用这个固定目标判断“是否超配”，
  避免目标随组合成员变化而漂移导致连续小额减仓（开发过程中实测到这种换手会把收益磨掉）。

### 1.4 交易节奏

- **退出信号每轮都检查**（止损、移动止损、急速下跌、信号反转），保证风险响应及时。
- **建仓/超配减仓只在“轮换槽位”评估**：每个新交易日槽位计数重置，`counter % 3 == 1` 的槽位
  （即每日第 1、4、7… 个新槽位，约每 30 分钟）才允许新建仓与减仓。价格噪声驱动的换手由此大幅下降。
- 报价与该股上次决策时完全相同（调度迟到/重放）时，本轮**不下单**，只更新状态（幂等保护）。

## 2. 参数表与理由

| 参数 | 值 | 理由 |
|---|---|---|
| `MAX_POSITIONS` | 4 | 8 只池内最多同时持有 4 只：分散但不摊薄到无意义的小仓 |
| `WEIGHT_CAP` | 0.35 | 单票最大 35% 净资产：够“敢下注”，又留出组合分散空间 |
| `DEFAULT_GROSS` | 1.00 | 默认不加杠杆。借款利息 6%/年、且无强制平仓，长期看杠杆只放大尾部风险 |
| `TARGET_VOL` | 0.005 | 波动率目标常数 `w∝1/vol` 的分子。日波动率 1% 的标的→50%（被 35% 上限截断），4% 的标的→12.5% |
| `VOL_FLOOR` / `VOL_CAP` | 0.005 / 0.06 | 防止极低波动标的吃掉全部预算、极高波动标的被压到接近 0 权重 |
| `VOL_WINDOW` | 20 | 约一个月日收益，兼顾稳定与响应；不足 5 个样本则改用日内区间 |
| `MIN_BUY_SCORE` | 0.002 | 约等于“确认 0.2% 以上动量”才动用资金。合成数据下把阈值从 -0.0005 提到 0.002 后，换手从 20+ 笔/周降到 3 笔以内 |
| `MIN_TRADE_DRIFT` | 0.04 | 单笔调整至少 4% 净资产：以 10 万元账户计约 4000 元，双边成本（含 5 元最低佣金）约为其 0.3%，可接受 |
| `ROTATE_EVERY` | 3 | 约 30 分钟评估一次建仓/减仓；10 分钟级动量噪声大，日频级响应又太迟 |
| `STOP_LOSS` | -9% | 相对成本止损。小于 8% 会被日常波动频繁触发，大于 12% 单票损失对组合冲击过大 |
| `TRAIL_STOP` | -12% | 自持仓期最高价回撤 12% 离场，锁定已有浮盈 |
| `TAKE_PROFIT` | +30% | 分批止盈一半，仅在轮换槽位评估；避免单票过度集中 |
| `CRASH_EXIT_MOVE` | -3%（清仓线 -4.5%） | 当日跌幅达 3% 先减半、达 4.5% 清仓。合成行情中一次全池 -3% 的冲击日若不止损，回撤要到 -9% 才触发，代价明显更大 |
| `EXIT_SCORE` | -0.02 | 综合分转负到一定程度即退出（动量策略的“信号消失”条件） |
| `EXIT_COOLDOWN_DAYS` | 2 | 止损后 2 个交易日内不重建同一标的，减少来回打脸与手续费 |
| `LIMIT_GUARD` | 0.004 | 距涨/跌停 0.4% 以内不买/优先卖；环境本就会拒单，这里避免无意义的挂单 |
| `MAX_DAILY_MOVE` / `MAX_INTRADAY_MOVE` | 0.15 / 0.105 | 过滤明显异常（脏数据、公司行为导致的跳变）而不是当成信号 |
| `SERIES_KEEP_DAYS` | 80 | 日序列长度：够算 20 日动量且 memory 远小于 64 KB |
| `MEMORY_BUDGET` | 60000 | memory 序列化长度预算，留出安全边际（协议上限 65536） |

所有费率、滑点、手数、股票池、负债上限均**从输入的 `environment` 读取**，不写死；示例行情与日期
也没有出现在代码里。

## 3. 数据不足时的行为

| 情形 | 行为 |
|---|---|
| `history` 只有 1 条 | 无跨日历史：仅当某股 `|intraday| ≥ 0.3%` 或槽内漂移 ≥ 0.3% 时给弱信号；否则**空仓** |
| `history` 为空 / 无有效报价 | `orders: []`，只更新 memory 与 commentary，正常退出 |
| 个股在本轮缺失或报价过期 | 该股不参与建仓，也不因缺数据被强制卖出；持仓按环境最后有效价估值 |
| 全部报价过期 | 不新建仓；已触发止损/急跌规则的持仓仍会挂卖单（环境会因报价不新而拒单，属预期） |
| 缺少某字段（如 `unavailable`、`pre_close`） | 容忍缺失，相关指标退化为可用部分或直接不给信号 |
| 只有日内、没有跨日历史 | 降级为日内/槽内动量模式，且要求 ≥0.3% 的明确波动才出手 |
| 账户无持仓、无可交易标的 | 返回空 orders；不会因为“必须交易”而乱下单 |

## 4. 买入、卖出与借款条件

**买入（同时满足）**
1. 该股本轮报价有效（年龄 0–600 秒、`vol > 0`），且未贴近涨停价；
2. `score > 0.002`，趋势未破坏，当日涨幅 ≤ 8%；
3. 有空仓位（持仓+计划买入 < 4）且处于轮换槽位；
4. 现金/敞口预算允许：先由**总敞口上限**（`gross_cap × 净资产`）限制，再由**可用现金**限制；
5. 交易金额 ≥ 4% 净资产，且为 100 股整数倍。

**卖出**
1. 逼近跌停、触发 -9% 止损、自高点回撤 -12%、综合分 < -0.02、中动量 < -5%、
   当日跌幅 ≤ -3%（减半）/ ≤ -4.5%（清仓）、+30% 止盈减半；
2. 数量 ≤ 该股 `sellable`，且为整手；**记忆显示当日买入的份额一律不卖**（T+1）；
3. 超配减仓：仅在轮换槽位，且超出目标权重部分 ≥ 4% 净资产时才执行。

**借款（负现金）**
- 默认敞口上限 1.00 且买入前按“可用现金（含计划卖出回款 - 上一轮未结算买单占用）”裁剪股数，
  因此正常路径不会产生借款；若账户已因环境原因处于负现金，策略**不新增**买入金额超过剩余额度
  （`max_debt + cash`）的部分，并把已有负现金视为“敞口已用满”。
- 利息由环境按自然秒计息，策略不重复扣减，也不读改 `interest_remainder`；回撤阶梯在借款状态下会
  自动把敞口压到 0，倾向先还债（由卖出回款自动减少负现金）。

## 5. 退出与风险控制

1. **单票止损**：成本 -9%。
2. **移动止损**：持仓期最高价 -12%（峰值由策略在 memory 内维护，逐轮更新）。
3. **信号反转**：综合分 < -0.02 或中动量 < -5% 离场。
4. **急速下跌**：当日跌幅 ≤ -3% 减半、≤ -4.5% 清仓；逼近跌停（距跌停 0.4% 内）优先卖出。
5. **止盈**：+30% 减半（轮换槽位）。
6. **组合回撤阶梯**：以环境提供的 `max_drawdown` 为基准，8%/15%/22%/28% 四档把总敞口上限
   降到 0.80/0.50/0.25/0，回撤期只减不加。
7. **冷却**：完整止损离场后 2 个交易日内不重建同一标的。
8. **换手控制**：最小交易规模 4%、仅在轮换槽位调仓、报价未更新时不下单。
9. **工程兜底**：任何异常都会被捕获，改为输出 `orders: []` + 安全 memory，退出码恒为 0，
   保证“本轮无信号”而不是“进程失败”。

## 6. memory 结构与升级兼容

输出 memory（`json.dumps` 长度控制在 6 万字符以内，实际约 1–2 KB）：

```json
{
  "schema": 1,
  "strategy_tag": "trend_vol_sampled_v1",
  "strategy_version": 1,
  "revision": "<输入 revision 原样回存>",
  "seen_versions": ["v1"],
  "seen_tags": ["trend_vol_sampled_v1"],
  "migrated": false,
  "obs": 137,
  "last_slot": "2026-03-05T13:20:00+08:00",
  "last_slot_key": "2026-03-05T13:20",
  "last_as_of": "2026-03-05T13:20:40+08:00",
  "last_date": "2026-03-05",
  "rotate_counter": 3,
  "equity": 98678.94,
  "peak": 100622.94,
  "max_drawdown": 0.0193,
  "cash": 1528.94,
  "gross_cap": 1.0,
  "series_keep_days": 80,
  "quote_marks": {"600519.SH": "2026-03-05T13:20:39+08:00"},
  "series": {"600519.SH": [["2026-02-02", 1508.3, 1499.0]]},
  "pos": {"600036.SH": {"entry": 35.27, "peak": 35.96, "tw": 0.35,
                        "buy_date": "2026-03-02", "entry_date": "2026-03-02",
                        "seen": "2026-03-05"}},
  "cooldown": {"000651.SZ": "2026-03-04"},
  "pending_round": {"submitted_at": "2026-03-05T13:20:40+08:00", "n": 2, "sells": 1, "buys": 1}
}
```

**升级兼容策略**
- 版本字段是 `schema`（memory 结构）+ `strategy_tag`/`strategy_version`（策略实现）。
  不依赖输入 `revision` 的具体取值。
- 所有读取都做**类型与取值校验**：`series` 支持 `[date, close]` 与 `[date, close, ref]` 两种行格式，
  `pos` 支持对象与数组两种写法，无法识别的条目直接丢弃——**只重建辅助状态，绝不清空账户、
  绝不动持仓与现金**。
- 旧版本 memory 里不存在的键（如 `tw`、`quote_marks`、`cooldown`）按缺省值处理：
  缺失 `tw` 时用当时的波动率目标重新设定一次；缺失 `buy_date` 时以账户 `sellable` 为权威。
- 发现不认识的 `schema`/`strategy_tag` 时置 `migrated = true` 并在 commentary 中体现，便于复盘定位。
- 体积保护：`series` 超预算时按 60/40/25/15/8/4/2 日逐级裁剪，仍超则退化为最小状态集，
  保证永不因 memory 过长而整轮失败。

## 7. 自测情况（合成数据，非真实行情）

用自写夹具按协议顺序回放（真实子进程、真实 executor：T+1、费用、滑点、涨跌停、计息、负债上限）：

1. 协议示例（单快照、空持仓）→ 合法 JSON；空 history → `orders: []`；非法 JSON 输入 → 仍返回合法 JSON；
2. 单日冷启动、5 日温和趋势、10 日含急跌（退出生效：3 买 3 卖，最终 1 仓）、3 只个股缺失、
   全部报价过期、旧版本 memory 迁移、横盘无信号（0 委托）、全池涨停（0 买单）、
   接近/超过负债上限（买单被限制为 0）；
3. 12 交易日 trace 检查：委托数量整手、卖出不超过 sellable、当日买入不挂卖单、
   现金从未突破 -200000、无任何协议违规（0 违规）；
4. 单次调用墙钟约 0.13–0.16 秒（含解释器启动），stdout 约 2 KB，memory 约 1–2 KB。

**未实测**：没有用真实行情跑过，也没有跨周/跨月的长期实盘对照；上述数字全部来自合成数据，
不构成任何收益预期。

## 8. 已知限制

1. **无复权因子**：日收益用 `reference_close` 近似，除权除息日会出现假跳变（策略用 ±15% 过滤兜底，
   但小比例分红送转仍会干扰动量）；公司行为对账期间不做任何自行调整。
2. **history 只有约一天的窗**：跨日动量依赖 memory 自建序列，因此**清空 memory 或换新账户会丢失
   多日动量**，策略会退化为日内模式（这也是首次运行时的正常表现）。
3. **仅 8 只标的、最多 4 仓**：组合分散度低，单票事件（跌停、停牌、公司行为）影响较大。
4. **日内动量可能来自噪声**：采样为当日累计快照而非 10 分钟 K 线，开盘后不久的信号可靠性最低，
   策略用 0.3% 阈值与轮换节奏降低这类噪声交易，但无法消除。
5. **成交假设保守**：策略按“下一轮新报价成交”设计，报价未更新即拒单；不补跑漏采时段，
   因此信号可能在最有利的时点错过（不保证收益）。
6. **不止损即长持**：未触及止损/移动止损/反转条件的持仓会一直持有，遇到长期阴跌行情回撤可能较大
   （靠回撤阶梯降低敞口，但不保证不亏）。
7. **手动参数**：所有阈值（止损 9%、急跌 3%、回撤档位等）来自小样本合成数据的经验校准，
   **没有做过参数敏感性/稳健性检验**，真实市场下未必最优。
8. **memory 是唯一状态**：临时目录、文件、环境变量都不使用；如果环境不传回 memory，
   策略会以“冷启动 + 仅当日快照”的方式运行（能正常工作，但会失去多日动量）。
9. **不接触外部世界**：不联网、不读项目文件、不自行定时，一切输入都来自 stdin，一切决策都来自
   输入数据本身。
