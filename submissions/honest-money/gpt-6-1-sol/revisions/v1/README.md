# 采样日级趋势与现金保护策略

- 生成模型确切名称：由操作者填写。
- 生成日期：2026-10-17，Asia/Shanghai。
- 适用协议：schema_version=2、next_observed_fresh_quote。
- 用途：A 股虚拟模拟；目标是控制风险并参与持续上涨趋势，不保证收益。

## 运行方式

保存程序为 strategy.py，由环境执行：

`python -X utf8 -I -S /submission/strategy.py`

程序每次只读取一个标准输入 JSON，输出一个包含 orders、memory、
commentary 的 JSON 对象，然后退出。

只依赖 Python 标准库。不联网，不读取业务文件、环境变量或本机时间，
不启动循环、后台服务或子进程。持续调度和实际撮合由外部环境负责。

## 行情与日级样本

所有时间转换为固定 UTC+08:00。

历史快照必须不晚于输入 as_of。有效报价需要满足：

- quote_time 与采集日期相同，位于工作日正常连续交易时间；
- 报价年龄在 0 至 environment.max_quote_age_seconds 之间；
- price 和累计 vol 为正；
- 行情源提供有效的正数跌停价、涨停价，价格未明显越界。

价格越界检查允许 0.011 元数值容差；涨跌停下单过滤使用协议规定的
0.001 元容差。

每只股票保存每天最后一个有效的 14:50—15:00 报价，作为“日末采样价”。
它可能是 14:50 的价格，不宣称为交易所正式收盘价。

只用日期严格早于本轮日期的样本计算趋势；当天样本可保存，但当日不会
纳入日级指标。缺少日末采样的日期直接跳过，不插值、不补历史、不虚构成交。

本文“20日”“5日”分别表示日末样本之间的 20、5 个间隔。漏采时，
其实际跨度可能更长。

当前报价只取最新历史快照，并按当前 as_of 重新检查新鲜度。
最新快照缺失的股票，不使用更旧快照补成当前行情。

累计成交量只用于判断报价是否有效。不把它当作区间成交量，也不使用
累计 open/high/low 构造十分钟 K 线。

## 趋势、选股和配置

每只股票至少需要 21 个先前日期的有效日末样本。

指标：

- MA20：最近 20 个日末采样价的算术均值。
- M20：最新日末采样价 / 第 21 个倒序样本价格 - 1。
- M5：最新日末采样价 / 第 6 个倒序样本价格 - 1。
- 波动率：最近 20 个采样收益率的总体标准差，不年化；
  计算排名和权重时下限为 0.8%。

普通调仓至少要求 min(4, 股票池数量) 只股票同时具备完整指标和当前有效报价。
当前固定八股池因此至少要求四只。任何已有持仓缺少当前有效报价时，
暂停普通调仓；其他持仓的风险退出仍可执行。

市场宽度为：

“具备指标且 M20>0、当前价格>=MA20 的股票数 / 当前股票池总数”。

缺失股票仍留在分母，使数据缺失时的仓位选择更保守。

| 市场宽度    | 基础目标股票敞口 |
| ----------- | ---------------- |
| >=60%       | 净资产的75%      |
| >=40%、<60% | 净资产的40%      |
| <40%        | 0%               |

候选股还必须满足：

- M20 >= 2%，过滤弱趋势；
- M5 > 0，要求近期方向一致；
- 波动率 <= 4%，避开当前样本中波动过大的股票；
- 不在个股退出冷却期。

新建仓或补仓还要求：当前未涨停，且价格不超过有效 pre_close 的 104%。
这用于减少追涨。已有持仓不会仅因涨停或当日上涨超过4%就失去候选资格，
但仍禁止在这些条件下加仓。

按 M20 / 波动率降序选择最多四只，分数相同按股票代码排序。
目标权重按波动率倒数分配，并施加：

- 单股目标权重最多25%；
- 每笔买入的压力预算最多为净资产20%；
- 600036.SH、000001.SZ、601398.SH 三只银行股合计目标权重最多40%。

这些上限用于控制集中度。被上限截去的资金不重新分配，保留为现金。
实际价格变化、延迟成交及不可卖持仓可能令实际权重暂时超过目标。

## 调仓、买入与交易成本

普通调仓窗口由 slot 判断：10:00—11:30、13:00—14:40，
且实际 as_of 仍须位于连续交易时间。

每日流程：

1. 先检查风险退出和负现金偿债。
2. 普通调仓先卖出超出目标的可卖整手。
3. 有卖单时，本轮不买；下一轮根据真实账户重新评估。
4. 应减仓却被 T+1、跌停或整手限制阻止时，继续等待。
5. 无需继续减仓后，进行一次买入评估，并记录 rebalance_date。

一次买入评估完成后，当日不再普通补仓；即使买单被拒，也不会假定成交，
下个交易日期重新根据账户计算。风险检查不受这个每日标记限制。

普通买单和非清仓减仓的最低触发金额为：

max(3000元, 净资产的4%)。

这个门槛用于减少小额交易和最低佣金损耗。退出候选名单的清仓、风控退出
和偿债卖出不受该金额门槛限制。

所有股数按照输入 lot_size 向下取整；单笔最多1000000000股。
已有零股不会使新买单产生非法非整手数量。

买入预算：

- 预留正净资产5%的现金；
- 不使用尚未实际到账的卖出回款；
- 按当日行情源涨停价与滑点估价中的较大值预算买价；
- 加入输入佣金率和最低佣金；
- 每笔扣减剩余现金预算及组合敞口预算，避免重复使用资金。

手续费、最低佣金、卖出税率、滑点、债务上限和交易单位从 environment 读取。
程序中的对应默认值只作为缺字段时的防御值；完整输入值优先。

实际成交、滑点、费用和账户变化全部以环境下一轮结算为准。
程序不设置委托价格，不自行扣费或修改账户。

## 借款和偿债

策略不主动使用借款增加股票仓位。

cash<0 时禁止所有买单，优先尝试卖出可卖持仓，目标覆盖债务并恢复
正净资产5%的现金缓冲。先保留已经生成的风控卖单，再按当前持仓估值
从大到小补充偿债卖单，不重复使用 sellable。

偿债数量按当前已知跌停价、佣金和卖出税保守估算，实际回款仍由环境确定。

当日涨停价不能约束跨日或长期漏采后的成交价格，因此现金保护无法绝对
保证未来结算后现金非负。若出现负现金，后续有效轮次会进入偿债流程。

借款利息由环境按照输入 annual_debt_interest 和真实时间维护；
策略不重复计息，也不修改 interest_remainder。

## 退出与组合风控

每个有效新轮次都检查：

- 当前价较账户平均成本下跌至少8%；
- 当前价较持仓期间策略实际观察到的最高有效价格下跌至少10%；
- 当前价低于 MA20 的98%；
- M20<-3%。

任一触发即尝试退出该股当前可卖整手。缺少趋势指标时，成本止损和
已有可见高点止损仍可工作。成本非正时跳过成本止损。

触发退出的股票设置5个已观察交易日期的禁买期；持续触发会续期。
这样减少刚止损后立即重新买回。组合冷却退出也会设置个股禁买期。

组合当前回撤使用：

max(0, 1 - account.equity / account.peak)。

它不是历史 max_drawdown；历史最大回撤不会永久触发清仓。

- 首次当前回撤达到12%：进入10个已观察交易日期的冷却期，
  尝试退出全部可卖持仓，期间禁止买入。
- 触发后，下一次触发线设为本次回撤再增加4个百分点，
  避免现金持有期间因原回撤未恢复而每天重新启动冷却。
- 当前回撤恢复到6%以下时，触发线重新设为12%。
- 冷却结束但当前回撤仍>=6%时，目标敞口上限降至25%。
- 净资产<=0时持续禁止买入，尝试退出可卖持仓。

冷却计数只在输入进入一个新的交易日期时减少一次。漏掉多个交易日，
恢复调用时也只减一次，不推测期间经历了多少交易日。

T+1、跌停、缺报价和下一报价跳空都可能阻止退出或扩大实际损失。
上述阈值是触发条件，不是保证成交的止损价格或最大亏损承诺。

## 除权参考价断点

当有效 pre_close 与 reference_close 的相对差异达到0.5%时，
保守地认为该股票历史价格口径可能不连续：

- 丢弃断点日期以前的日末样本；
- 不推测复权因子、分红金额或送转比例；
- 重新积累趋势所需样本；
- 通过断点标签重置该持仓的辅助跟踪高点。

账户 reconciled_on 标签变化时也重置辅助高点。
所有股数、成本和现金继续使用权威账户，不自行对账。

0.5%阈值用于忽略微小差异，但不能准确识别所有公司行为；
参考价滞后也可能造成保守误判。

## 数据不足、重复调用与异常

- 首次仅一条历史且空仓：输出空 orders，开始积累样本。
- 缺少趋势样本：暂停普通调仓，不用短历史替代长期信号。
- 个股缺报价：不生成该股委托，不把价格视为零。
- 持仓缺当前有效报价：暂停普通调仓，等待可见行情。
- pending 非空：不叠加新委托，等待旧委托结算。
- as_of 或 slot 不晚于上次记录：不重复下单。
- 不合法的协议、执行模式或槽位：输出空 orders。
- 未预期的输入或计算异常：stderr 记录异常类型，stdout 输出合法空单对象，
  重置辅助 memory，后续从有效数据重建；账户不会被程序清空。

## memory 结构与升级

当前辅助状态版本为 strategy_schema=1：

| 字段                  | 内容                                                       |
| --------------------- | ---------------------------------------------------------- |
| symbols               | 每股最多65条 [日期, 日末采样价, quote_time]，以及 reset_on |
| trails                | 当前持仓的可见最高价 peak 和价格口径 tag                   |
| bans                  | 各股剩余禁买日期计数                                       |
| risk                  | 下一回撤触发线 next_dd、组合冷却计数 cooldown              |
| day                   | 上次处理的交易日期                                         |
| last_as_of、last_slot | 策略自身上次处理的时间和槽位                               |
| rebalance_date        | 已完成普通买入评估的日期                                   |
| revision              | 最近输入版本标识，仅记录，不假定固定值                     |

保留65条日末样本，为21条指标需求提供余量；不会无限复制 history。
保存前按默认 json.dumps 长度检查，超过62000字符时逐条删除最旧样本，
为65536字符限制留出余量。

revision 变化但 strategy_schema 仍受支持时保留辅助状态。
未知版本或无法识别的旧 memory 会重建；已知版本逐字段清洗、限长，
忽略无效记录。未来若改变字段语义，应增加 strategy_schema 并实现明确迁移，
或继续采用保守重建。

重建只影响指标、跟踪高点及冷却等辅助信息，不修改账户持仓、债务、
净资产或历史收益。重建后可能再次经历等待样本的阶段。

## 已知限制

- 趋势策略可能在横盘中反复交易，也可能错过快速反转。
- 股票池较小，市场宽度并不代表全市场。
- 未提供完整复权信息，参考价检查不能消除全部公司行为影响。
- 高价股票可能因100股一手、单股上限和资金规模而无法买入。
- 目标上限、最低金额、现金预算与整手约束可能使实际仓位明显低于目标。
- 无法合法卖出的零股会保留；需要完全退出时，可能阻止后续买入。
- 未模拟盘口、排队或成交量容量，只遵守环境采样撮合规则。
- 风控和委托均有下一报价延迟，无法保证收益、止损幅度或绝对无债务。
- 参数依据是可解释的风险取舍，没有经过真实行情收益优化。

## 实际验证情况

生成过程中已在 Windows、Python 3.12.5 下使用隔离启动参数执行合成测试：

- 14个独立进程用例：包含题给初始 JSON、充分历史买入、重复轮次、
  pending、T+1、整手卖出、组合回撤、负现金、旧 memory、
  过期报价、参考价断点、缺失报价及跌停。
- 90次连续状态更新：验证只传入单条新快照时，memory 能跨轮积累日末样本，
  历史充足后产生实际买单。
- 500组随机协议边界用例：检查输出结构、股数整手、卖出数量和 memory 限制。

发现并修正了已有非整手持仓导致补仓股数不整手的边界问题，
修正后上述测试通过。

Linux 部署未实测；真实腾讯行情、宿主完整撮合链路及长期收益回测未实测。
合成测试仅验证程序行为与协议约束，不代表未来投资表现。
