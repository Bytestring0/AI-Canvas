# 将军棋 AI 策略说明

## 算法概述

采用**优先级驱动的多目标策略**，核心逻辑为每 tick 按以下优先级顺序执行：

1. **紧急防守** (Priority 0): 检测将军是否受到直接威胁（敌方单位在相邻格），若存在则优先调度周边我方单位全军增援
2. **战略攻击** (Priority 1-3): 按目标价值/距离比排序，优先攻击敌方将军 > 中立城市 > 敌方城市
3. **边境扩张** (Priority 4): 向视野边缘未知区域推进，探索新领土
4. **随机侦察** (Fallback): 无明确目标时，从强兵格子向随机方向派出半数军队侦察

目标评分公式：`score = value / (distance + 1)`，确保近距离高价值目标优先。

## 状态记忆设计

memory 对象仅存储**关键战略信息**，避免 JSON 序列化超限（≤32768 字符）：
   字段 | 类型 | 用途 | 大小估算 |
 |------|------|------|----------|
 | `myId` | number | 自身 ID | 固定 |
 | `generalPos` | {x,y} | 将军坐标 | 固定 |
 | `enemyGenerals` | {playerId: {x,y,lastSeen,army}} | 敌方将军位置与最后可见时间 | O(N)，N=玩家数≤16 |
 | `neutralCities` | [{x,y,army}] | 中立城市列表 | O(M)，M=中立城市数≤136（16人辽阔地图） |
 | `myCities` | [{x,y}] | 己方城市列表 | O(K)，K=己方城市数 |
 | `lastTick` | number | 上次决策 tick | 固定 |

**不存储完整地图**：依赖环境持久化已侦察地形（`terrain` 一旦可见即永久记忆），仅在 memory 中追踪动态信息（所有权、军队数）。

## 复杂度分析
 | 操作 | 时间复杂度 | 空间复杂度 | 说明 |
 |------|------------|------------|------|
 | 可见单元格扫描 | O(W×H) | O(W×H) | W=宽度, H=高度，最大 168×160=26880 |
 | 目标排序 | O(T log T) | O(T) | T=目标数量，通常 <100 |
 | 路径选择 | O(1) | O(1) | 贪心方向选择，非完整 BFS |
 | 防守检测 | O(1) | O(1) | 仅检查将军周围 4 格 |

**最坏情况**：16 人辽阔地图（26880 格），单次 `decide` 扫描全部可见格子（≤26880）+ 目标排序（≤200 个目标），实际测试中 JavaScript 引擎可在 <50ms 内完成。

## 局限性

1. **视野依赖性强**：仅能基于当前可见信息 + 记忆的历史信息决策，对隐藏敌方动向反应滞后
2. **路径规划简化**：采用贪心方向选择（Manhattan 距离优化）而非 A* 或 BFS，可能绕远路
3. **军队分配粗糙**：按单个格子军队数分配，未考虑多路并进的协同效应
4. **记忆不完整**：不追踪敌方非将军单位的历史位置，无法预测其移动趋势
5. **防守单一**：仅防守将军，未对己方城市进行主动防护

## 设计取舍
 | 取舍点 | 选择 | 原因 |
 |--------|------|------|
 | **路径算法** | 贪心方向 vs BFS | BFS 复杂度 O(W×H) 对大地图（26880 格）可能超时，贪心方向 O(1) 更可靠 |
 | **记忆策略** | 关键信息 vs 完整地图 | 完整地图 JSON 序列化后约 40KB（168×160，每格 1-2 字符），超过 32KB 限制 |
 | **目标评估** | 静态优先级 vs 动态评分 | 动态评分需更多计算，静态优先级在 200ms 内更易实现 |
 | **军队调度** | 单格子最大军队 vs 多格子协同 | 多格子协同需复杂规划，单格子策略简单且有效 |
 | **随机性** | 确定性哈希 vs Math.random | 要求可复现对局，使用 `seed+tick+coords` 哈希生成伪随机 |
 | **防守策略** | 被动防守 vs 主动拦截 | 主动拦截需预测敌方路径，计算量大，被动防守更稳定 |

## 战术细节

- **攻击决策**：对敌方将军和中立城市使用全军（`half: false`）进行直接攻击；对远距离目标使用半数军队（`half: true`）以保留防守力量
- **侦察策略**：无目标时从兵力最多的格子派出半数军队向未知方向移动，平衡探索与资源消耗
- **威胁评估**：仅检测将军相邻格的直接威胁，响应速度最快
- **生产考量**：隐含考虑生产率（`g = 1 + floor(tick/200)`），早期扩张优先，后期聚焦消灭敌方
