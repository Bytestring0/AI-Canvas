# 将军棋 AI 策略说明

## 1. 核心战术思路
### 1.1 整体阶段划分
策略不使用显式阶段状态机，而是通过价值评估自动适配对局节奏：
- **早期扩张**：无高价值目标时，优先占领周边空地，扩大视野与领土，通过分兵维持多方向扩张效率
- **中期发展**：发现中立城市后自动引导兵力集结，抢占城市提升单位时间产兵量，同时持续探索地图寻找敌方位置
- **后期决战**：发现敌方将军后将其设为最高优先级目标，全力集结兵力推进；同时检测敌方威胁，必要时回防己方将军

### 1.2 核心决策机制：价值驱动的贪心选择
每 tick 基于统一的收益评估函数，贪心选择 4 个收益最高的移动指令，前序移动结果会实时更新模拟状态用于后续决策。
- **目标优先级**：敌方将军 > 敌方城市 > 中立城市 > 敌方普通领土 > 带探索价值的中立空地 > 普通空地
- **兵力成本**：进攻损失的兵力作为成本直接从收益中扣除，避免无意义的兵力消耗
- **增援价值**：根据格子到最近高价值目标的实际路径距离计算增援收益，通过距离梯度引导兵力自动向目标集结，无需显式集结指令

### 1.3 扩张与探索策略
- 默认使用 `half` 模式移动，保留出发格半数兵力，维持多点扩张能力
- 优先向未知区域边缘移动，通过占领新格子自动解锁 8 邻域视野，逐步揭开战争迷雾
- 未知地形格子不会作为移动目标，避免撞山浪费移动次数

### 1.4 进攻逻辑
- 进攻城市、将军等高价值目标时，算法会自动比较 `half` 与全量移动（`half: false`）的收益，选择攻击力更强的全量模式
- 兵力不足时，通过增援收益梯度自动完成多回合兵力集结，逐步推进到目标附近
- 敌方目标附带额外价值权重，占领敌方领土同时削弱敌方产兵能力，收益高于中立目标

### 1.5 防守机制
- 实时计算可见敌方单位到己方将军的最短路径距离，当距离小于 6 格时触发防守状态
- 防守状态下大幅提升回防将军的增援权重，引导前线兵力向将军方向回撤
- 依托将军与城市的持续产兵能力，形成天然防守支点

## 2. 状态记忆设计
`memory` 对象用于持久化跨 tick 的静态地形信息，避免重复侦察，所有内容均可 JSON 序列化：
- `neutralCities`：已发现的中立城市坐标与驻军数量。中立城市驻军固定，一次侦察永久有效
- `enemyGenerals`：已发现的敌方将军坐标。地形标记永久保留，将军位置不会改变
- `enemyCities`：已发现的敌方城市坐标

每 tick 开始时执行记忆更新：
1. 扫描当前可见区域，将新发现的城市、将军加入对应列表
2. 清理已被己方占领的中立城市、已消失的敌方目标
3. 仅存储地形级静态信息，不存储动态兵力数据，避免过期信息干扰决策

## 3. 算法复杂度分析
设地图宽度为 W，高度为 H，目标点总数为 K（中立城市 + 敌方将军 + 敌方城市，通常小于 20）。

### 时间复杂度（单 tick）
1. 地图扫描与记忆更新：`O(W·H)`
2. 未知邻居数量预计算：`O(W·H)`
3. 目标距离场计算：K 次 BFS，单次 BFS 为 `O(W·H)`，总计 `O(K·W·H)`
4. 4 步贪心移动选择：每步遍历所有己方格子，每个格子评估 4 方向 × 2 种移动模式，总计 `O(W·H)`

整体时间复杂度为 `O(K·W·H)`。在最大尺寸地图（约 2.8 万格）、10 个目标的极端场景下，单次决策运算量约 30 万次基础操作，远低于 200ms 时限。

### 空间复杂度
- 距离场、模拟状态数组等均为 `O(W·H)` 空间
- 记忆存储量为 `O(K)`，可忽略不计

## 4. 设计取舍与局限
### 4.1 贪心策略的局限
- 采用单步贪心而非全局多步规划，可能陷入局部最优（例如分兵过度分散、集结路径非全局最短）
- 未做敌方行为预判，无法反制敌方佯攻、绕后等战术
- 4 次移动的组合未做全量搜索，仅通过顺序贪心选择，并非组合最优解

### 4.2 迷雾信息利用
- 仅基于已侦察地形进行决策，不主动推测未知区域地形分布
- 敌方兵力仅在视野内可知，无法推断视野外的敌方集结与移动意图
- 未记录敌方兵力历史变化，无法估算敌方产兵节奏与总兵力

### 4.3 确定性与可复现性
- 全程不使用非确定性输入（`Math.random`、`Date` 等），所有决策完全基于输入状态
- 多目标收益相同时按固定遍历顺序选择，保证同地图种子、同对局配置下结果完全可复现

### 4.4 简化假设
- 增援收益使用距离倒数近似，未精确计算未来收益的时间折现
- 防守触发阈值为固定距离，未根据敌方兵力规模动态调整
- 未针对组队模式做专门优化，自由混战与组队模式共用同一套逻辑
- 未处理多敌方目标的优先级排序优化，仅按最短距离选择目标

## 5. 潜在优化方向
- 引入束搜索（Beam Search）做有限步前瞻，提升决策深度
- 增加敌方兵力推断与意图识别模块，预判敌方进攻方向
- 为组队模式添加队友增援、协同进攻逻辑
- 采用显式集结点机制优化城市进攻的兵力集结效率
- 加入地形预判，基于已探索地形推断未知区域的山地分布规律
